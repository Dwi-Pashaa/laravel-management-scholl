## Penggunan Aplikasi

buka direktori project di terminal anda lalu masuk ke direktori folder aplikasi dan ketikan kode di bawah ini

```php
cp .env.example .env
```

Setelah memasukan code di atas masukan juga kode berikut untuk menginstall library yang di gunakan aplikasi LuxBliss Vogue

```php
composer install
```

Setelah itu masukan juga code di bawah ini untuk mengaktifkan apliasinya

```php
php artisan key:generate
```

```php
npm install
```

```php
npm run build
```
